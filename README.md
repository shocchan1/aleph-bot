# AlephBot

My second modular built with Node.js and Discord.js.

This project is primarily created for learning purposes while also serving as my personal Discord server bot. It is a complete reboot of my first Discord bot project, which had a poor code structure and was difficult to maintain. This version focuses on writing cleaner, more modular, and scalable code.

## Features

- Slash Commands
- Recursive Command Loader
- Event Handler
- Modular Project Structure
- Custom Bot Presence
- Easy-to-Extend Command System

## Installation

npm install
node src/index.js

Create a **.env** file in the project root and configure the following variables:

TOKENLOGIN=your_bot_token
BOTID=your_application_id
